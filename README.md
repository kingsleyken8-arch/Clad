# ACETENNIS — Play Strong.

A tennis-academy landing page built with **Vite + React + TypeScript +
Tailwind CSS**. All imagery is AI-generated with **Higgsfield**.

Highlights:

- **Sky hero** with a giant `PLAY STRONG.` display headline, drifting clouds
  and a background-removed (transparent) tennis player that drops into frame.
- **A travelling character**: the very same player follows you as you scroll and
  "turns" into a new throw / catch pose at each section (serve toss → lunging
  catch → ready stance), then retires into the footer.
- **Building Champions** about section, **Training Program** cards, and a
  pixel-faithful **Member App** activity-tracker dashboard (the second design).
- Consistent typography (Anton display / Archivo headings / Inter body) and a
  chartreuse-lime, black, white and sky-blue palette throughout.
