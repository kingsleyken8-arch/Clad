# Meridian

Concept landing page for a cross-border payments company. The hero illustration is
drawn from particles that hold one landmark for four seconds, burst apart, and
re-form as the next: Colosseum, Abuja City Gate, Brooklyn Bridge, Parthenon,
Sydney Opera House, Great Wall of China.

Plain HTML, CSS and JavaScript, no build step.

- `script.js`: the particle landmarks. Timing and particle count are at the top.
- `page.js`: header, line icons, the dotted globe, scroll scenes and the menu.
- `assets/shapes/`: the landmark drawings, generated with Higgsfield.

The company, figures, fees and rates are illustrative.
