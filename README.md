# VANGUARD

A fullscreen hero landing page for the VANGUARD creative agency — built with
**Vite + React + TypeScript + Tailwind CSS**, featuring a looping background
video, animated navigation, and staggered hero entrance animations.

## See it live — one click

Pick either button, sign in (free), and it will build and host the site for you.
No code or terminal needed.

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/kingsleyken8-arch/Clad)
&nbsp;&nbsp;
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/kingsleyken8-arch/Clad)

Both auto-detect the settings in `netlify.toml` / `vercel.json`
(build command `npm run build`, output directory `dist`), so you can accept the
defaults and click through.

## Run it locally

```bash
npm install
npm run dev      # http://localhost:5173
```

## Build for production

```bash
npm run build    # outputs to dist/
npm run preview  # preview the production build
```
