# Landmark particle hero

A hero and "what we do" section where the illustration is drawn from particles.
The particles hold one landmark for four seconds, burst apart, and re-form as the
next in under a second: Colosseum, Abuja City Gate, Brooklyn Bridge, Parthenon,
Sydney Opera House, Great Wall of China. All six share one composition: a tall
element down the left edge and the rest sweeping right across the hero.

Plain HTML, CSS and JavaScript, no build step. The drawings in `assets/shapes/`
were generated with Higgsfield and are sampled into dots in the browser by
`script.js`. Timing and particle count are set at the top of that file.
