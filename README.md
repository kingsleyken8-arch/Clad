# LOST — Concept Not Found

A cyber-editorial 16:9 hero built with **Vite + React + TypeScript +
Tailwind CSS + GSAP**, recreated from a poster design. The chrome robotic
hand holding a pink rose is AI-generated with **Higgsfield** (transparent
PNG, background removed).

Highlights:

- **Cut-shape cards** — every card is a rounded-polygon SVG path (tag
  notches, chamfered corners, edge bites), generated by `src/lib/shape.ts`
  so all curves stay smooth and consistent.
- **Fixed 1600×900 design stage** uniformly scaled to the viewport, so the
  layout never distorts or reflows.
- **Real glassmorphism** — a frosted panel with live `backdrop-filter`
  blur over the card and rose stem.
- Halftone dot backdrop, ghost `ROSES / POSSESSÉ` typography, glitch-sliced
  `LOST / LOST` logotype, red asterisk status pill, barcodes, vertical side
  rails, the big `89`, and the `color tone.` swatch plate.
- GSAP entrance animation, floating rose, mouse parallax and
  `prefers-reduced-motion` support. Fonts are self-hosted.
