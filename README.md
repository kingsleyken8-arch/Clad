# Huile — More room for good work.

Landing page for Huile, an AI workforce for everyday business. Plain HTML, CSS
and JavaScript with no build step: open `index.html` or serve the folder.

- `index.html`, `styles.css`, `script.js`: the page, its styling, and the scroll-driven scenes.
- `assets/`: hero and customer story videos and stills (generated with Higgsfield), plus self-hosted fonts.
- `assets/hero-alt.mp4`: an earlier hero take, kept as an alternate and not used by the page.

Customer names, quotes, statistics, benchmark figures, compliance badges and the
integrations list are placeholders and must be replaced before launch.
