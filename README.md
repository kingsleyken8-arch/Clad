# Ronin

A one-page site for a creative digital studio. Plain HTML, CSS and JavaScript with no build step.

## Editing

| What | Where |
| --- | --- |
| All text, names, numbers, awards | `index.html` |
| The studio name | Search `index.html` for `RONIN` (the hero spells it one letter per `<span>`) |
| Colours and sizes | The variables at the top of `styles.css` (`--bg` cream, `--red` accent) |
| The clock's city | `timeZone` in `script.js`, and the `LOS` label in `index.html` |

## Media

Nothing here was generated for this site. Every clip and photograph is a preview sample from Higgsfield's own catalogue, re-encoded locally, and stands in until real project work replaces it.

| Files | Used for | Catalogue source |
| --- | --- | --- |
| `p1.mp4` | Featured card and first project | "Ink Riot" preset preview |
| `p2.mp4` | Second project | "Studio slide" preset preview |
| `p3.mp4` | Third project | "Cold vision" preset preview |
| `p4.mp4` | Fourth project | "Blue depth" preset preview |
| `reel.mp4` | Showreel | A montage cut from nine preset previews |
| `t1` to `t3`, `award` | Testimonial portraits, awards image | Soul style samples |

Replace a file and keep its name, and the page picks it up. Each `.mp4` has a `.jpg` poster of the same name.

## Placeholders to replace before launch

The studio name, the project names, the testimonials, the figures, the award names, the email address and all media.
