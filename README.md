# VANGUARD

A fullscreen hero landing page for the VANGUARD creative agency — built with
**Vite + React + TypeScript + Tailwind CSS**, featuring a looping background
video, animated navigation, and staggered hero entrance animations.

## 🔗 Live site (permanent link)

**https://kingsleyken8-arch.github.io/Clad/**

This is the permanent home of the site. It rebuilds and updates automatically
on every push via GitHub Actions — **bookmark it once** and it always shows the
latest version. No dashboards, no re-finding it.

> **One-time setup to switch it on:** in this repo go to
> **Settings → Pages → Build and deployment → Source: GitHub Actions**.
> After that, every push deploys automatically to the link above.
> (The deploy workflow lives in `.github/workflows/deploy.yml`.)

## Run it locally

```bash
npm install
npm run dev      # http://localhost:5173
```

## Build for production

```bash
npm run build    # outputs to dist/
npm run preview  # preview the production build
```
